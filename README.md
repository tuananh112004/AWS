# ExamCraft

Ứng dụng thi trắc nghiệm với chế độ luyện tập và thi.

## Cài đặt

1. Cài Node.js và MySQL.
2. Tạo database `aws` trong MySQL.
3. Chạy `npm install` để cài dependencies.
4. Chạy `npm start` để start server trên port 3000.
5. Mở `index.html` trong browser.

## Tính năng

- Tạo và import câu hỏi từ TXT.
- Lưu đề thi vào MySQL.
- Chế độ luyện tập và thi.
- Hỗ trợ 5 đáp án A-E.
